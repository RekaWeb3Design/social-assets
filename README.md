# social-assets

Public image and video files for Réka Víg / The WOW Studio social posts (LinkedIn, Facebook, Instagram), scheduled through Buffer.

Buffer can only import media from a public URL, so files live here and are linked via `raw.githubusercontent.com`.

## Structure

- `YYYY-MM/YYYY-MM-DD-<channel>-<lang>.<ext>` — one file per post, named by publish date
  - e.g. `2026-10/2026-10-15-linkedin-EN.png`

## Notes

- Everything in this repo is public, including files for posts not yet published.
- No client names, prices or other identifying details go into these files.
